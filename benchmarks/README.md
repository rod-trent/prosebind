# Benchmarks

We do not build a benchmark. We win the ones that exist and publish the numbers.

- `flawedfictions/` — harness for FlawedFictions (arXiv 2504.11900)
- `constory/` — harness for ConStory-Bench

Corpora are never vendored into this repo; see `.gitignore`. Report precision and recall
separately — precision is the number that matters. See `DESIGN.md` § 12.
